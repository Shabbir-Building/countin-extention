# LinkedIn Comment Counter

A simple Chrome extension that tracks how many comments you post on LinkedIn — daily, weekly, and monthly.

## Installation

1. **Download the repo**
   On the GitHub repo page, click **Code → Download ZIP**.

2. **Unzip it**
   Find the downloaded ZIP file and unzip/extract it. Remember the folder location.

3. **Open Chrome extensions page**
   Go to `chrome://extensions` in your address bar (or Menu → Extensions → Manage Extensions).

4. **Turn on Developer mode**
   Toggle **Developer mode** on (top-right corner of the page).

5. **Load the extension**
   Click **Load unpacked**, then select the unzipped folder (the one containing `manifest.json`).

6. **Done**
   The extension icon should now appear in your toolbar. Visit [linkedin.com](https://www.linkedin.com) and the comment counter will show up on the page automatically.

## Updating

If you download a newer version later, unzip it and click the **Reload** (circular arrow) icon on the extension's card at `chrome://extensions`.
